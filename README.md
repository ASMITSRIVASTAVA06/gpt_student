# Student Success Intelligence

An integrated Streamlit dashboard for student success scoring, at-risk identification, explainable recommendations, and data-quality review.

This repository is being built as a hackathon-ready prototype. The included datasets are synthetic demo records only and must not be interpreted as real institutional data.

## Quick start

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\generate_sample_data.py
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```
